# 🌟 Task Management Frontend

This is the **frontend** for the Task Management Application built with **React** and styled using **Ant Design**. It interacts with a Node.js/Express backend, where tasks are stored in **MongoDB** and user data is stored in **PostgreSQL**.

---

## ⚙️ Tech Stack

- **React** (Functional Components, Hooks)
- **Ant Design** (UI library)
- **Axios** (HTTP client)
- **React Router DOM** (Client-side routing)
- **JWT Auth** (Token-based login)
- **Environment Config** (`.env`)

---

## 🖼️ Features

- 📋 Create, view, update, and delete tasks
- 👤 User login and role-based dashboard
- 🧑‍💼 View tasks by user ID (admin or user)
- 📅 Task filtering based on due date, status, and priority
- 📦 Fully integrated with backend (Node + MongoDB + PostgreSQL)
